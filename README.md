# Troject Title
Excel Data Cleaning & Dashboard Project

# Project  Description
This project demonstrates data cleaning, pivot table analysis, and dashboard creation in Excel. 
The goal was to clean a raw sales dataset, summarize key metrics using pivot tables, and create a visual dashboard to support decision-making.


# file structure
data file         → Contains the cleaned Excel dataset with all sheets
output/           → Contains screenshots of pivot tables and dashboard
README.md         → This file


# data file's sheets explanation
- Sheet1: Raw/Imported Data
- Sheet2: Cleaned Data used for analysis
- Sheet3: Pivot Tables summarizing sales by product and region
- Sheet4: Dashboard with charts and KPIs


# tools used
Excel (Data cleaning, Pivot Tables, Formulas, Dashboard visualization)

# How to view
1. Open 'cleaned_sales_data.xlsx' in the datafile to explore the dataset.
2. Review pivot tables and dashboards in 'output/' folder for visual insights.
